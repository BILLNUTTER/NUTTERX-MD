# NUTTER-XMD

A powerful WhatsApp multi-device bot by [@nutterxtech](https://github.com/nutterxtech).

## WhatsApp Pairing

Deploy the pairing website first and use it to link your WhatsApp account and generate your SESSION_ID.

**Pairing website:** To be updated after deployment.

## Deploy Your Own Bot

Use the button below to create a new Heroku app using this production repository.

[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/BILLNUTTER/NUTTERX-MD)

During deployment:

1. Enter your SESSION_ID from the pairing website.
2. Enter your OWNER_NUMBER in international format, without `+`.
3. Configure any other bot settings you need.
4. Press Deploy.

Each deployment creates a separate bot instance. You can repeat this process with different session IDs to deploy multiple bots.

## Features

- WhatsApp multi-device support
- Pairing and session management
- Admin dashboard
- Group management and moderation
- Status automation
- Customizable bot settings
